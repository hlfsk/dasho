# 📝 Журнал фидбека

Сюда пишем заметки после каждого пользовательского теста. Файл за человека.

## Как использовать

1. Скопируй `_template.md` → переименуй в `2026-05-08_имя.md` (дата + кто)
2. Заполни во время или сразу после теста
3. Раз в 5 человек — открой все файлы и составь сводку:
   - Что повторяется (топ-3 проблемы) → чинить в первую очередь
   - Что вызвало вау → удвоить
   - Что никто не использовал → кандидат на удаление

## Где смотреть фидбек из приложения

Кнопка **📝** в левом нижнем углу. Юзер пишет → открывается mailto на твою почту, плюс сохраняется локально в его `localStorage` под ключом `dasho.feedback.history`.

В DevTools Console это можно достать:
```js
JSON.parse(localStorage.getItem('dasho.feedback.history') || '[]')
```

## Идеи которые могут прийти из фидбека

- Топ-проблемы — добавь в `docs/issues.md`
- Идеи фич — добавь в `docs/wishlist.md`
- Цитаты для питч-дека — выписывай отдельно: «Это типа Scratch для красоты?»
