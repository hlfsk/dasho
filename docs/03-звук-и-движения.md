# Звук и движения

## Звук может приходить откуда угодно

Источники звука в lupsmachine — отдельные ноды, каждая выдаёт сигнал «звук»:

- **🎤 Микрофон** — живой микрофон компьютера
- **🎵 Звук-файл** — твой mp3 / wav. Кнопка «Выбрать файл», потом ▶︎
- **🎬 Видео-файл** — у видео тоже есть выход «звук», тоже можно анализировать

Любой из них подключи к **🎚️ Анализу звука** — и получишь те же 5 чисел.
Так визуал может реагировать на песню из файла, а не только на твой голос.

## Звук разбирается на части

Когда играет музыка или ты говоришь — это один поток.
Внутри этого потока спрятано **много разной информации**.
Нода **🎚️ Анализ звука** разбирает звук на 5 кусочков:

| Что | Что значит |
|---|---|
| **громкость** | насколько вообще шумно (0 = тишина, 1 = крик) |
| **бас** | низкие частоты — бочка, гул, бас-гитара |
| **середина** | голос, гитара, основной звук инструмента |
| **верх** | хай-хэт, шипение, свист |
| **бит** | короткая вспышка в момент удара (триггер) |

Это четыре **числа** (от 0 до 1) и один **триггер** (срабатывает на бите).

## Как этим пользоваться

1. Создай **🎤 Микрофон** → нажми «Включить».
2. Создай **🎚️ Анализ звука**.
3. Соедини **Микрофон → звук** с **Анализ звука → звук**.

В ноде «Анализ звука» побегут полосочки — это значения сейчас.
Постучи по столу — увидишь, как мигает красный кружок «beat».

Теперь у тебя 5 свежих сигналов, которые можно подавать в эффекты.

## Движения распознаёт MediaPipe

Это нода **🤚 MediaPipe жесты**. Принимает видео с камеры,
ищет на нём твоё тело и говорит:

| Что | Что значит |
|---|---|
| **видео + скелет** | то же видео, что пришло на вход, но с нарисованным скелетом лица и рук поверх — для отладки и красоты |
| **рот открыт** | число от 0 (закрыт) до 1 (широко) |
| **ладонь** | триггер — открытая ладонь повёрнута к камере |
| **палец** | триггер — указательный палец вытянут (как пистолет) |
| **щипок** | триггер — большой и указательный пальцы коснулись |
| **щипает (0/1)** | плавное число: 0 = пальцы далеко, 1 = в щепотку |
| **руки в кадре** | число — сколько рук видно (нормировано 0..1) |
| **моргание** | триггер — оба глаза моргнули одновременно |
| **лицо в кадре** | 1 если есть, 0 если нет |
| **палец X**, **палец Y** | координаты указательного пальца (0..1) — для рисования |

Связь:
1. Создай **📷 Камера** → включи.
2. Создай **🤚 MediaPipe жесты**.
3. Соедини **Камера → видео** с **MediaPipe → видео**.

Подожди пока модели загрузятся («готов, нужен видео-вход» → потом «анализирую ✓»).

## Цвета проводов и типы сигналов

Не все ноды можно соединить чем угодно. Цвет провода = тип сигнала:

- 🟢 **зелёный** — видео (картинка)
- 🔵 **синий** — звук
- 🟡 **жёлтый** — число от 0 до 1
- 🔴 **красный** — триггер (короткий импульс)

Если ты тянешь провод между несовпадающими типами —
он просто не нарисуется. Это не ошибка, это защита, чтобы ты не сломал шоу.

## Хитрости

- **На один вход можно повесить несколько проводов** — например, сразу два триггера на «спуск» бабблов: и палм, и моргание. Тогда баббл будет всплывать на оба.
- **Один выход можно раскинуть на много входов** — бас может одновременно крутить размер бабблов и силу хвоста.
- Если **палм / палец / моргание** не срабатывают — отойди от камеры подальше, или включи свет.

## Идеи

- **Постучи в бочку → бабблы**: Микрофон → Анализ → бит → Бабблы:спуск.
- **Громче говоришь → больше пузыри**: Анализ → громкость → Бабблы:размер мод.
- **Открыл рот → запустил эмодзи-мозаику** (через Mix-ноду, чтобы плавно переключить).
