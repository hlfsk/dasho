# Первое шоу за 5 минут

Соберём такую цепочку:
**ты открываешь рот → на экране всплывают слова**.

## Шаг 1. Запусти

Дважды кликни `start.command` → откроется браузер с пультом.
На холсте сразу стоят две ноды: **Камера** и **Финальный коллаж**.

## Шаг 2. Включи камеру

Нажми кнопку **▶ Включить камеру** в ноде «Камера».
Браузер спросит разрешение — соглашайся.
Должна появиться надпись **идёт ✓**.

## Шаг 3. Соедини камеру с коллажем

У ноды «Камера» справа есть зелёный кружочек (выход «видео»).
У ноды «Финальный коллаж» слева такой же зелёный кружочек (вход «видео»).

Зажми мышкой зелёный кружочек камеры, тяни к зелёному кружочку коллажа,
отпусти.
Между ними появится зелёная линия — это провод.

Камера теперь идёт в коллаж: видишь себя на фоне.

## Шаг 4. Добавь распознавание лица

Нажми **+ Добавить ноду** (розовая кнопка слева сверху).
Выбери в категории «Анализ» → **🤚 MediaPipe жесты**.
Подождёт несколько секунд («загружаю модели…»).

Соедини зелёный выход «Камера → видео» с зелёным входом «MediaPipe → видео».
Теперь нода видит твои движения.
Открой рот — циферки рядом с «РОТ» поменяются.

## Шаг 5. Добавь бабблы

Нажми **+ Добавить ноду** → «Эффекты» → **💬 Бабблы**.

У бабблов три входа:
- **видео** (зелёный) — что показывать на фоне
- **спуск** (красный) — что запускает баббл
- **размер мод.** (жёлтый) — модулирует размер

Соедини:
1. **Камера → видео** в **Бабблы → видео** (зелёный провод)
2. **MediaPipe → рот открыт** или **палец** в **Бабблы → спуск** (красный провод)

⚠ **«Рот открыт» — это число**, но если соединишь с триггером — провод не нарисуется (типы не совпадают).
Используй любой из ТРИГГЕРОВ (красные кружочки): **палм / палец / моргание**.

## Шаг 6. Замени, что идёт в коллаж

Удали зелёный провод **Камера → Финальный коллаж** (просто кликни по нему).
Сделай новый провод: **Бабблы → видео** в **Финальный коллаж → видео**.

## Готово

Покажи ладонь камере → выскочит «УРА!». Палец — «ВАУ». Моргни глазами — «БУМ».

Дальше попробуй: добавь **✨ Хвост (трейл)** между Бабблами и Коллажем
— теперь движения оставляют след.

## Что ещё попробовать

- В ноде «Бабблы» поменяй **тип → пузыри** — будут просто цветные шары вместо слов.
- Поменяй **палитру → пастель** — мягкие цвета вместо неона.
- Добавь **😀 Эмодзи-мозаика** между камерой и коллажем — превратит видео в сетку лун.
