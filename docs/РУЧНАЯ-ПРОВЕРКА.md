# Ручная проверка — список для тебя в поезде

Поставь ✓ если работает, ✗ если нет. На ✗ оставь короткий комментарий —
я починю когда вернёмся.

⚠ **Перед началом:** открой http://localhost:8889, нажми **Cmd+Shift+R**,
кликни «Очистить» если там что-то есть.

---

## БАЗА — провода и сокеты

- [ ] Перетащи провод от **Камера: видео** к **Финальный коллаж: видео** — нарисуется зелёная линия?
- [ ] Кликни по проводу — он удаляется?
- [ ] Сверни ноду стрелочкой ▾ — провода прячутся?
- [ ] Раскрой обратно — провода вернулись?
- [ ] При hover на сокет — есть подсказка с типом?

## ИСТОЧНИКИ ВИДЕО

### 1. Камера (встроенная)
- [ ] Нажал «Включить камеру» → видишь себя?
- [ ] В выпадающем списке устройств — список твоих камер?

### 2. iPhone через NDI
- [ ] На Mac запущен NDI Webcam Input?
- [ ] В iPhone NDI HX Camera стримит на сеть?
- [ ] В ноде «iPhone-камера» в селекте появился «★ NDI Video»?
- [ ] Выбрал — Включил — видишь iPad/iPhone?

### 3. OBS Virtual Cam
- [ ] OBS запущен, сцена собрана, нажат «Start Virtual Camera»?
- [ ] В ноде «OBS Virtual Cam» появилась OBS Virtual Camera?
- [ ] Поток идёт в финальный коллаж?

### 4. Видео-файл
- [ ] Кнопка «Выбрать видео» открывает file picker?
- [ ] Выбранное видео играет, идёт в финальный коллаж?
- [ ] Звук тоже выходит на «звук» (можно подать в Анализ)?

### 5. Видео по ссылке
- [ ] Пресет «Big Buck Bunny» загружается?
- [ ] Своя ссылка на mp4 — играет?
- [ ] HLS-стрим (m3u8) — играет в Safari? (в Chrome — может не играть нативно)

### 6. Универсальный плеер
- [ ] mp4 ссылка → играет видео?
- [ ] PNG ссылка → показывает картинку?
- [ ] mp3 ссылка → играет звук, выход звук работает?
- [ ] svg ссылка → рендерит SVG?

### 7. Захват экрана
- [ ] Нажал «Выбрать окно/экран» → системное окно появилось?
- [ ] Выбрал окно VLC / IINA / любое → его содержимое идёт в финал?

### 8. Текст
- [ ] Ввожу текст в поле → отображается?
- [ ] Меняю цвет / размер / позицию → работает?
- [ ] Кнопка «Случайно» меняет на случайное слово?

### 9. SVG-картинка
- [ ] Пресет «звёздочка» сразу видна как картинка?
- [ ] Загружаю свой .svg → показывается, статус «загружено: NxN»?
- [ ] Слайдер «вращение» — крутится?
- [ ] Подключаю Анализ звука: бас → крутить от сигнала → крутится на басах?

### 10. 3D-модель
- [ ] Пресет «кубик / сфера / тор» — сразу видны?
- [ ] Загружаю свой .glb → показывается?
- [ ] Загружаю по ссылке (с Sketchfab экспорт .glb) → работает?
- [ ] Крутится по слайдерам?

### 11. Шейдер
- [ ] Все 5 пресетов работают (плазма / волны / лучи / звёзды / калейдоскоп)?
- [ ] 4 слайдера «параметр 1..4» — что-то меняют (смотри подсказки внутри ноды)?
- [ ] Подключаю Анализ звука: бас → шейдер: общая модуляция → реагирует?

### 12. Веб-плеер (iframe)
- [ ] Пресет «Shadertoy» открывает iframe поверх холста?
- [ ] Cables.gl ссылка работает?
- [ ] Sketchfab embed — открывается?
- [ ] Слайдер «прозрачность» — меняет alpha окна?
- [ ] Слайдеры X/Y/W/H — меняют положение и размер?

### 13. Градиент / Шум
- [ ] Градиент: 6 пресетов работают?
- [ ] Шум: 3 типа (ч/б, цветной, неон)?

## АНАЛИЗ

### 14. Микрофон + Анализ звука
- [ ] Микрофон включается?
- [ ] Подключил «Микрофон: звук» → «Анализ звука: звук» — полоски vol/bass/mid/high шевелятся?
- [ ] Постучал по столу → красный кружок «beat» вспыхивает?

### 15. MediaPipe
- [ ] Подключил «Камера: видео» → «MediaPipe: видео» — статус «анализирую ✓»?
- [ ] Группы выходов видны (ЛИЦО / РУКИ / ПАЛЬЦЫ / ТЕЛО / НОГИ)?
- [ ] Открыл рот → число «рот открыт» меняется от 0 к 1?
- [ ] Поднял ладонь → индикатор «палм: да»?
- [ ] Соединил пальцы как «ОК» → индикатор «щипок: да»?
- [ ] Подключил «MediaPipe: видео + скелет» → «Финальный коллаж: видео» — видно скелет лица и рук?

### 16. LFO
- [ ] LFO в режиме sine — индикатор плавно бегает?
- [ ] Подключил LFO к параметру другой ноды → анимация работает?
- [ ] Меняю форму волны — реакция меняется?

### 17. Метроном
- [ ] BPM 120 → красная точка пульсирует раз в полсекунды?
- [ ] Подключил «тик» → «Бабблы: спуск» — на каждый удар выскакивает баббл?
- [ ] Меняю BPM → темп изменяется?

### 18. Генератор движения
- [ ] Маленький превью с движущейся точкой работает?
- [ ] Режим «по кругу» / «восьмёрка» / «по курсору» — работают?
- [ ] Подключил X/Y → Paint X/Y → точка рисует на холсте?

### 19. Считалка (Math)
- [ ] A + B, A × B, max, min — работают?
- [ ] Если B не подключён — берётся слайдер «B по умолчанию»?

### 20. MIDI вход
- [ ] APC key25 / Launchpad подключены по USB?
- [ ] Нажал «Подключить MIDI» — устройство появилось в списке?
- [ ] Нажал кнопку на пэде → нота определяется (триггер «note», число «note_n»)?
- [ ] Покрутил фейдер → CC1..CC8 меняются?
