# 📖 DÄSHO Cookbook — рецепты шоу

Сборник готовых связок: что подключить, что подкрутить, и что получится.

Все рецепты собираются **в один клик** через кнопку `📚 Шоу` в шапке. Здесь — текстовое описание, чтобы понимать «что внутри» и подкручивать под себя.

---

## 🟢 Новички (2-3 ноды)

### 1. Камера + Хвост 🎥
**Эффект:** видео с камеры со светящимся следом за движениями.

```
Камера ──video──▶ Хвост ──video──▶ Финальный коллаж
```

**Параметры Хвоста:** «затухание 0.94» = длинный хвост; «0.7» = короткий и бодрый.

**Совет:** подключи `Хвост.очистить!` к `MIDI.note` или к кнопке Arduino — будешь сбрасывать след в такт.

---

### 2. Тень-силуэт 👤
**Эффект:** тебя видно как чёрный/цветной силуэт на цветном фоне (классика теневого театра).

```
Камера ──▶ Силуэт ──▶ Финальный коллаж
```

**Режимы Силуэта:** `чёрный силуэт`, `цветной`, `прозрачная тень`, `только контур`, `двойной свет`. По умолчанию — «прозрачная тень».

**Совет:** добавь Trail после Силуэта → летающие призраки. Триггер `инвертировать!` меняет фон/фигуру местами.

---

### 3. Кинопроектор 📺
**Эффект:** старая VHS-плёнка с царапинами, scanlines, виньеткой.

```
Камера ──▶ CRT ──▶ Финальный коллаж
```

**Параметры:** «царапины частые», «пятна (плёнка)» — добавь, чтобы плёнка выглядела поношенной. Параметр «интенсивность» 0..1 — сила всего эффекта.

---

## 🎵 Аудио-реактив

### 4. Звук → 3D-частицы 🎵
**Эффект:** микрофон управляет облаком частиц. Бас раздувает, громкость = масштаб.

```
Микрофон ──audio──▶ Анализ звука ──┬──bass───▶ Частицы 3D ──▶ Финал
                                    └──volume─▶
```

**Совет:** в Анализ звука добавь Усилитель `auto` между bass и Particles — частицы будут одинаково реагировать на тихий и громкий микрофон.

---

### 5. Плазма на басу 🌀
**Эффект:** генеративный шейдер «плазма» дышит на басу музыки.

```
Микрофон ──▶ Анализ звука ──bass──▶ Шейдер (preset=плазма) ──▶ Финал
```

**Совет:** замени preset на `звёзды` или `калейдоскоп` — каждый по-своему реагирует на `mod`.

---

### 6. Глитч на ударе ⚡
**Эффект:** на каждый бит музыки — резкая вспышка глитча.

```
Камера ──video──▶ Glitch ──▶ Финал
Микрофон ──audio──▶ Анализ звука ──┬──bass──▶ Glitch.amount
                                    └──beat──▶ Glitch.вспышка!
```

**Параметры Glitch:** «хвост вспышки 0.85» = резкий удар; «0.95» = долгое затухание.

---

## 🤲 Жесты (MediaPipe)

### 7. Хлопок → Бабблы 🤲
**Эффект:** хлопаешь руками — на экране всплывают слова.

```
Камера ──▶ Hand Detail ──┬──video─▶ Бабблы ──▶ Финал
                          └──хлопок!─▶ Бабблы.спуск
```

**Совет:** в Бабблы текстарии «свои слова» вписывай через запятую: `БУМ, ВАУ, СЛУШАЙ, ХЛОПОК`. Включи распознавание голоса (`голос → бабблы = русский`) — будут появляться твои реальные реплики.

---

### 8. Палец рисует 🎯
**Эффект:** указательный палец оставляет линию, щипок включает/выключает рисование.

```
Камера ──┬──▶ Finger Brush ──┬──x──▶ Paint
          │                   ├──y──▶
          │                   └─draw─▶
          └─────────video────────────▶ Paint.фон-видео
```

**Совет:** «сглаживание дрожи 60%» — линия плавная. Включи «Apple Pencil = да» если рисуешь на iPad — давление = толщина.

---

### 9. Частицы из тела 💫
**Эффект:** из суставов вылетают звёзды/круги, хлопок = взрыв.

```
Камера ──┬──▶ Hand Detail ───clap──▶ Body Particles.взрыв!
          └──video───────────────▶ Body Particles ──▶ Финал
```

**Параметры Body Particles:** «откуда вылетают = руки», «форма = звёзды», «гравитация −0.05» (летит вверх). «Размер 30, прозрачность 80%».

---

### 10. Улыбка → текст 🎭
**Эффект:** чем шире улыбаешься, тем больше слово на экране.

```
Камера ──video──▶ Face Mimic ───smile──▶ Text.размер мод. ──▶ Финал
```

**Совет:** замени `smile` на `surprise` (удивление) или `frown` (нахмуренность) — текст растёт от других эмоций. Можно так же подключить `head_tilt → Text.X`, чтобы текст летал за наклоном головы.

---

## 🔥 Безумие (4-8 нод)

### 11. Тепловизор + Калейдоскоп 🔥
**Эффект:** твои движения горят и преломляются как в калейдоскопе.

```
Камера ──▶ Heatmap ──▶ Kaleidoscope ──▶ Финал
```

**Параметры:** Heatmap палитра «огонь», чувствительность 8-12. Калейдоскоп: 6 граней, медленное вращение.

---

### 12. Slit-scan времени ⏱
**Эффект:** каждая колонка кадра — другой момент времени. Двигаешь рукой → она «размазывается» по экрану.

```
Камера ──▶ SlitScan ──▶ Glow ──▶ Финал
```

**Параметры:** скорость прокрутки 4-8px/кадр, ширина щели 4. Glow добавляет свечение поверх. Для медленного театрального эффекта — скорость 2.

---

### 13. Звёздное поле + ритм 🌌
**Эффект:** звёзды летят, на каждый бит сбрасывается хвост и появляются новые.

```
Микрофон ──▶ Анализ звука ─┬─high──▶ Шейдер (звёзды).mod
                             └─beat──▶ Trail.очистить!
Шейдер ──video──▶ Trail ──▶ Финал
```

**Совет:** для медитативного варианта — убери Trail.очистить и сделай длинный хвост.

---

### 14. Двойная вселенная 🪞
**Эффект:** камера → калейдоскоп → жидкое искажение → старый кинопроектор.

```
Камера ──▶ Kaleidoscope ──▶ Fluid ──▶ CRT ──▶ Финал
```

**Совет:** опасный по производительности. Если дёргается — закрой ноды чтобы скрыть превью.

---

### 15. Призрачное эхо 👻
**Эффект:** призраки актёра отлетают за ним светящимися шлейфами.

```
Камера ──▶ Силуэт (тень) ──▶ Trail ──▶ Glow ──▶ Финал
```

**Параметры Силуэта:** режим «прозрачная тень», прозрачность 70%, мягкость краёв 0.4. Trail затухание 0.95 (длинный шлейф).

---

### 16. Полный аудио-контроль 🎛
**Эффект:** микрофон управляет ВСЕМ.

```
Камера ──┬──▶ Glitch.video
          └──▶ Body Particles.video
Микрофон ──▶ Анализ звука ─┬─bass──▶ Glitch.amount
                             ├─beat──▶ Glow.вспышка!
                             └─vol───▶ Body Particles.размер
Glitch ──▶ Glow ──▶ Mix.A
Body Particles ─────────▶ Mix.B
Mix ──▶ Финал
```

Это самая сложная связка — пример что можно собрать на сцене.

---

## 🤖 Железо (Arduino, Flipper Zero, MIDI, OSC)

См. раздел **«🤖 Внешнее железо»** в [`README.md`](../README.md) с примерами кода для Arduino. Шаблоны:

- **🎛 Arduino: 1 потенциометр → Glitch** — крутишь ручку → меняется глитч
- **🎚 Arduino: 4 ручки → Шейдер** — DJ-pad из 4 потенциометров
- **🔘 Arduino: кнопка → Бабблы** — нажатие = всплывает баббл
- **📏 Arduino: дистанция → 3D-частицы** — HC-SR04 → размер облака
- **🐬 Flipper: D-pad → сцены** — кнопки переключают эффект через Mix
- **📡 Flipper: Sub-GHz → Glitch** — каждый радиосигнал = вспышка
- **🎹 MIDI → Шейдер** — APC mini / Launchpad управляет p1..p4
- **📱 OSC с телефона → 3D** — наклоны телефона крутят модель

## Свои рецепты

Когда соберёшь свою связку — сохрани её через **Save 💾** или скачай файлом через **📥** в плашке сцен. Поделись JSON-файлом с друзьями — у них восстановится твоя сцена в один клик.

Если нашёл какую-то крутую комбинацию — запиши сюда новый рецепт по тому же шаблону.
