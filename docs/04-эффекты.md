# Эффекты

Эффекты — это ноды, которые **берут видео на вход и отдают видео на выход**.
Ставь их в цепочку — сигнал проходит через все по очереди.

## ✨ Хвост (трейл)

Оставляет за движением «хвост». Чем сильнее затухание — тем короче хвост.

**Параметры:**
- **затухание** — насколько быстро тает хвост
- **смешение** — режим наложения (обычное / светлее / screen / multiply / разница)

**Вход «затухание мод.»** — модулируй числом (например, басом).

## 💬 Бабблы

На каждый триггер — всплывает баббл. Со словом или просто пузырь.

**Параметры:**
- **размер** — насколько большие
- **длительность** — сколько секунд живут
- **тип** — слова или просто пузыри
- **палитра** — неон, пастель, или белый

**Вход «размер мод.»** — число модулирует размер.

## 🖌️ Рисование пальцем

Линия рисуется указательным пальцем (или щипком). Кривая — плавная Безье.

**Входы:**
- **фон-видео** — что показывать под рисунком (опционально)
- **X**, **Y** — координаты пальца (от 0 до 1)
- **рисую (0/1)** — рисуем сейчас (1) или нет (0)
- **очистить** — триггер, чтобы стереть холст

**Параметры:**
- **толщина** — толщина линии
- **цвет** — выбор цвета (или «радуга» для авто-смены)
- **затухание** — линия тает со временем (для эффекта «дыма»)
- **зеркало X** — переворачивать ли по горизонтали (камера обычно зеркалит селфи)

**Готовая связка** — так подключают для жеста «щипком»:

```
Камера → MediaPipe → видео → Paint:фон-видео
              MediaPipe → палец X → Paint:X
              MediaPipe → палец Y → Paint:Y
              MediaPipe → щипает (0/1) → Paint:рисую
                                                 │
                                                 ▼
                                         Финальный коллаж
```

Результат: соединил большой и указательный палец — рисуешь по экрану.

## 🔀 Микшер

Смешивает 2 видео-входа в одно.

**Параметры:**
- **A ↔ B** — слайдер
- **смешение** — режим наложения

Подключи **громкость** к слайдеру A↔B → авто-микс по музыке.

## Идеи цепочек

**Голос → бабблы:**
```
Микрофон → Анализ звука → бит → Бабблы:спуск
Камера → Бабблы:видео → Финальный коллаж
```

**Песня из файла → дискотека:**
```
Звук-файл → Анализ звука → бас → Хвост:затухание мод.
Камера → Хвост → Финальный коллаж
```

**Текст летит на басах:**
```
Звук-файл → Анализ звука → бас → Микшер:A↔B
Текст «ВАУ» → Микшер:B
Камера → Микшер:A → Финальный коллаж
```

**Рисование пальцем поверх живого видео:**
```
Камера → MediaPipe → (всё привязали к Paint, см. выше)
       → Финальный коллаж
```
