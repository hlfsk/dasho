# DÄSHO app

Визуальный пульт для AV-шоу. Drag&drop ноды на масштабируемом холсте,
соединяй проводами — собирай шоу из камеры, микрофона, MIDI, MediaPipe-жестов
и эффектов.

📖 **[docs/MAP.md](docs/MAP.md)** — карта кода: где что менять (лого, шрифты, цвета).
📖 **[docs/COOKBOOK.md](docs/COOKBOOK.md)** — рецепты шоу.
🔗 **[share-server/README.md](share-server/README.md)** — деплой share-сервера на Cloudflare за 5 минут.

## Запуск

```
./start.command
```

Откроется `http://localhost:8889`. Стек — чистый ES6 без сборщика.

## Палитра нод (20 шт.)

### 🎬 Источники (12)
- 📷 **Камера** — встроенная или USB; выбор устройства из списка (включая виртуальные камеры NDI Tools, Camo)
- 🎤 **Микрофон**
- 🎵 **Звук-файл** — mp3/wav, выход audio
- 🎬 **Видео-файл** — mp4/webm, выходы video + audio
- 🔗 **Видео по ссылке** — URL, mp4/HLS, demo-пресеты
- 🖥️ **Захват экрана** — ловит окно/вкладку (для VLC, IINA, Tagtool)
- 🔤 **Текст** — настраиваемая строка как видео
- 🖼️ **SVG-картинка** — твой SVG или встроенные пресеты, с авто-вращением
- 🌈 **Градиент** — анимированный, 6 пресетов
- 🌫️ **Шум** — пиксельный мусор, ч/б или цветной
- 🌀 **Шейдер** — WebGL-генератор: плазма / волны / лучи / звёзды
- 🎹 **MIDI вход** — APC/Launchpad через WebMIDI: ноты + 8 CC

### 🔍 Анализ (2)
- 🎚️ **Анализ звука** — vol / bass / mid / high / beat (FFT + beat-детект из meemoo)
- 🤚 **MediaPipe жесты** — рот / ладонь / палец / щипок / руки / моргание / лицо + координаты пальца + видео с скелетом-оверлеем

### ✨ Эффекты (4)
- ✨ **Хвост (трейл)** — canvas с composite-смешением (логика meemoo)
- 💬 **Бабблы** — слова или пузыри на триггер
- ✦ **Частицы** — система частиц, управляется MediaPipe (положение пальца, щипок)
- 🖌️ **Рисование пальцем** — плавная Безье-линия по координатам пальца/щипка

### 🔀 Маршрут (1)
- 🔀 **Микшер** — A↔B crossfade с режимами наложения

### 🖼️ Выход (1)
- 🖼️ **Финальный коллаж** — fullscreen на проектор

## Холст

- pan: пробел + drag (или ПКМ-drag, средняя кнопка)
- zoom: колесо мыши

## Сокеты типизированы

🟢 видео · 🔵 звук · 🟡 число · 🔴 триггер. Соединяются только сокеты одного цвета.

## Параметры

**Все слайдеры или select-ы**, никакого ручного ввода чисел. Единственное text-поле — у ноды «Текст» (там вводишь произвольную строку).

## Как подключать внешний мир

| Источник | Как попадает в lupsmachine |
|---|---|
| iPhone камера | NDI HX Camera → NDI Tools на Mac → Webcam → нода «Камера» |

| USB-микроскоп | прямо в «Камеру», выбор устройства |

| VLC / IINA с видео | Запустить отдельно → ScreenCapture |
| APC key25 / Launchpad | USB → MidiInput |

| Любая шейдер-программа | пока пресеты ShaderSource; ISF в следующих фазах |

## 🤖 Внешнее железо: Arduino / Flipper Zero / MIDI / OSC

В категории **«ЖЕЛЕЗО»** в кнопке `📚 Шоу` готово 8 связок которые включаются одним кликом. Ниже — как подключить твоё устройство.

### Arduino через USB Serial (Web Serial API)

Работает только в **Chrome / Edge** (не Safari).

1. Загрузи на Arduino скетч который пишет числа в `Serial`:

   ```cpp
   // 1 потенциометр на A0 → один поток в нужный sock
   void setup() { Serial.begin(9600); }
   void loop() {
     int v = analogRead(A0);          // 0..1023
     Serial.println(v / 1023.0, 3);   // "0.547\n"
     delay(20);
   }
   ```

   Для **4 потенциометров** (slot1..slot4) — пиши через запятую:

   ```cpp
   void loop() {
     Serial.print(analogRead(A0) / 1023.0, 3); Serial.print(",");
     Serial.print(analogRead(A1) / 1023.0, 3); Serial.print(",");
     Serial.print(analogRead(A2) / 1023.0, 3); Serial.print(",");
     Serial.println(analogRead(A3) / 1023.0, 3);
     delay(20);
   }
   ```

   Для **кнопки** на D2 — println'аем при нажатии:

   ```cpp
   void setup() {
     Serial.begin(9600);
     pinMode(2, INPUT_PULLUP);
   }
   void loop() {
     if (digitalRead(2) == LOW) {     // нажата
       Serial.println(1);
       delay(200);                    // антидребезг
     }
   }
   ```

2. В DÄSHO добавь ноду **Serial-вход** → выбери порт → скорость 9600 → подключись.
3. У ноды есть выходы: `slot1..slot4` (числа), `last` (последнее число), `trigger` (всплеск на каждое сообщение).
4. Соединяй: `slot1 → Glitch.amount`, `trigger → Bubbles.spuск` и т.п.

### Flipper Zero

Flipper в режиме **USB UART** работает как обычное Serial-устройство:

1. Установи на Flipper приложение которое шлёт данные через GPIO/USB (например свою FAP-апликуху на FlipperScript) — либо использует встроенный CLI.
2. В DÄSHO ту же ноду **Serial-вход** на скорости которую слёт Flipper (обычно 115200).
3. Шаблон **«Sub-GHz scanner → Glitch»** — каждое пойманное радио-сообщение запускает вспышку.
4. Шаблон **«D-pad → сцены»** — D-pad переключает Mix между двумя эффектами.

### MIDI (APC mini, Launchpad, MIDI-клавиатура)

Работает в Chrome/Edge.

1. Подключи USB → нода **MIDI вход** появится в списке устройств.
2. Выходы ноды: `slot1..slot8` — первые 8 CC, `note` — нота, `vel` — velocity.
3. Шаблон **«MIDI → Шейдер»** — 4 первых CC уже подключены к параметрам калейдоскопа.

Через **IAC Driver** (Audio MIDI Setup → Show MIDI Studio) можно принимать MIDI из Ableton Live, Logic, Reaper.

### OSC с телефона/планшета

Установи на телефон **GyrOSC**, **TouchOSC** или **Mrmr**, направь на IP компьютера, порт 9000.

1. Запусти **`./bridge/start-bridge.command`** (UDP→WebSocket мост на Node.js).
2. В DÄSHO нода **OSC-вход** автоматически подключится.
3. Выходы: `slot1..slot8` — соответствуют адресам `/1`, `/2`, …
4. Шаблон **«OSC → 3D»** — наклоны телефона крутят 3D-модель.

Подробнее про мост — `bridge/README.md`.

## Архитектура

```
src/
  main.js         — оркестратор + регистрация типов + цикл tick
  canvas.js       — pan/zoom + дотс-фон
  node.js         — базовый класс Node + реестр типов
  socket.js       — типы сокетов + can-connect
  wires.js        — SVG-провода с учётом zoom
  dragging.js     — drag нод
  palette.js      — палитра (+ Добавить ноду)
  util.js         — isDrawable / intrinsicSize
  nodes/*.js      — реализации (по одной на файл)
```
